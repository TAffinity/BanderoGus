# BanderoGus 🎮

BanderoGus is an interactive browser project built with vanilla JavaScript, HTML, and CSS.  
The project demonstrates DOM manipulation, event-driven interactions, and simple UI animation logic.

---

## 🚀 Features
- Interactive user experience in the browser  
- Form handling and validation  
- Animated goose effect triggered by user actions  
- Built with vanilla JavaScript (no frameworks)  
- Responsive and simple UI using HTML & CSS  

---

## 🛠️ Technologies
- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

---

## 🎯 Purpose of the project
This project was created as a learning exercise to practice:
- DOM manipulation  
- Event handling in JavaScript  
- Working with forms  
- Structuring small frontend applications  
- Creating interactive UI behavior

---

## ▶️ How to run
Simply open `index.html` in your browser.

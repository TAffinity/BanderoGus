BanderoGus 🎮

BanderoGus is a small browser-based game built with vanilla JavaScript, HTML, and CSS.
The project focuses on interactive gameplay mechanics, DOM manipulation, and simple game logic.

🚀 Features
Interactive gameplay in the browser
Built with pure JavaScript (no frameworks)
Simple and responsive UI using HTML/CSS
Event-driven logic (clicks, actions, updates)

🛠️ Technologies
HTML5
CSS3
JavaScript

🎯 Purpose of the project
This project was created as a learning exercise to practice:
DOM manipulation
Event handling in JavaScript
Structuring small frontend applications
Building interactive UI components

▶️ How to run
Simply open index.html in your browser.
